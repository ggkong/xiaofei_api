# Sub2API Windows 本地归档

适用：Windows 10 / 11。普通 Intel、AMD 电脑下载 x64；Windows ARM 电脑下载 ARM64。
无需安装 Node、Python、Go，也无需服务器密码或管理员 API Key。

1. 将 ZIP 完整解压，在解压目录双击 `Install.cmd`。
2. 选择一个专用的本地文件夹，如 `D:\Sub2API`。请勿选择整个盘符、系统目录或网盘同步目录。
3. 工具会打开服务器管理页。登录管理员账号，填写电脑名称，点击“配对电脑”。公钥会自动填入；如未填入，可复制安装窗口中 `ssh-ed25519` 开头的公钥。
4. 回到安装窗口按回车，安装当前 Windows 用户的自动任务及桌面 `Sub2API Archive` 快捷方式。
5. 本地查看页会打开。首次同步较慢，可查看状态；配对公钥约 15 秒生效，失败后可点击“立即同步”重试。

自动任务每 30 分钟运行，并在登录后尝试同步。需要此 Windows 账号处于登录状态、电脑联网且服务器 SSH 22 端口可达。关机、退出登录、睡眠、网络中断时不传输；服务器继续保存新记录，下次同步补齐。初次传输超过单次时限时，下一次继续补齐。

默认“仅备份”：同步完成不会删除服务器正文。管理页显示本机确认条数后，才可启用“释放服务器历史正文空间”，并选择服务器保留的最近天数（默认 7）。只有本机已持久写入、校验且确认的旧正文才迁移，服务器保留摘要、姓名、模型与调用索引。较早的完整正文从本地快捷方式查看。服务器 PostgreSQL 空间逐步回收为可复用空间，系统可用磁盘不一定立即增加。

重要：迁移后本地硬盘是较早正文的主要存储。保留该目录并额外备份；关闭本地查看工具及同步任务后，再复制整个归档目录（含 archive.db、可能存在的 -wal/-shm 文件）到另一块盘。不要只复制正在写入的 archive.db。不自动清理本地记录，服务器删除索引也不会删除本地记录。若原归档目录丢失，已迁移正文不能从服务器补回。换电脑时先恢复整个归档目录，再重新配对。

本地目录保存内容寻址压缩块，重复上下文复用同一份字节，每次调用仍独立保留。查看页可搜索姓名、模型和问题/回复摘要，按会话筛选调用，展开捕获的完整上下文与工具调用，查看请求/转发/服务商声明/客户端模型，并导出原始 JSON。大整数按原始 JSON 保存。媒体通常为外部链接，不代表附件文件也已下载；服务器早期已省略或截断的内容不能补回。

数据经固定服务器公钥验证的 SSH 加密传输。电脑使用独立 Ed25519 密钥；私钥由当前 Windows 用户的 DPAPI 保护，仅公钥提交服务器。此归档身份无 shell、端口转发或其他管理接口。管理员可在“保存到我的电脑”关闭允许同步，即时撤销后续数据请求。不要上传 identity.key、整个 config 目录或其他私钥文件。

本地浏览器页面仅监听 127.0.0.1 随机端口，通过临时会话授权访问，关闭它的控制台窗口即可结束查看服务。默认数据并未加密存储，目录 ACL 限制为当前用户和 SYSTEM；如需保护遗失的整块硬盘，可自行启用 Windows 提供的磁盘加密。

配置及同步状态：`%LOCALAPPDATA%\Sub2APIArchive\config`。
查看最近状态：

    "%LOCALAPPDATA%\Sub2APIArchive\archive-desktop.exe" status --config "%LOCALAPPDATA%\Sub2APIArchive\config"

全量完整性检查（大档案可能耗时较长）：

    "%LOCALAPPDATA%\Sub2APIArchive\archive-desktop.exe" verify --config "%LOCALAPPDATA%\Sub2APIArchive\config"

暂停自动同步：Windows“任务计划程序”中禁用 `Sub2APIArchive-你的用户 SID`。
卸载自动任务：右键以 PowerShell 运行 `Uninstall.ps1`，只移除任务和快捷方式，保留归档和身份文件。也应在服务器管理页关闭此电脑的同步授权。
发布包提供 SHA256SUMS.txt 供校验，程序未使用商业代码签名证书。
